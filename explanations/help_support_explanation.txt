Given the current evolution of DVL Theory, I would treat **Help & Support** as a hybrid of:

1. **Offline-first support experience**
2. **Online synchronization when available**
3. **User feedback collection**
4. **Issue reporting and diagnostics**
5. **Knowledge base / FAQs**

This aligns with your existing architecture where:

```text
User Profile
Study Preferences
Notification Preferences
Progress Engine
Hive Storage
```

are already offline-first.

---

# My Recommendation

Do NOT send reported problems directly to the server.

Instead:

```text
User submits issue
      ↓
Store locally in Hive
      ↓
Mark as "Pending Upload"
      ↓
When internet available
      ↓
Sync to server
      ↓
Mark as "Submitted"
```

This follows the same philosophy as:

```text
Progress Data
User Profile
Study Preferences
```

and prevents losing reports when:

```text
No internet
Poor network
App closes unexpectedly
```

# 1. FAQs

Most scalable approach:

```text
assets/json/faqs.json
```

Example:

```json
[
  {
    "question":"How are mock tests scored?",
    "answer":"You need 70% or higher to pass."
  },
  {
    "question":"Can I use the app offline?",
    "answer":"Yes. Practice tests work completely offline."
  }
]
```

Then:

```dart
FaqService
```

loads them.

Benefits:

```text
No server required
Easy to update later
Localized later
Searchable
```

# 3. Report A Problem

This is the most important feature.

Instead of just a text box:

### Collect

```text
User ID
App Version
Theme
Platform
Timestamp
```

Automatically.

Plus:

```text
Problem Category
Description
Screenshot (optional)
```

---

Example:

```dart
class SupportTicket {
  final String id;
  final String category;
  final String description;
  final String screenshotPath;
  final DateTime createdAt;
  final bool uploaded;
}
```

Stored locally.

# Server API

Since you've now decided to store reported problems:

I would add a dedicated endpoint.

Example:

```text
POST /support/ticket
```

Payload:

```json

  "ticket_id":"...",
  "user_id":"...",
  "category":"Mock Test",
  "description":"Timer froze at question 14",
  "app_version":"1.0.0",
  "platform":"android"
}
```
